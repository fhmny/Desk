# تجربة Creative Desk ببيانات وهمية

قاعدة التجربة جاهزة في `desk/backend/desk-demo.db`، ومصدر بياناتها [seed_demo.py](../backend/seed_demo.py). تحتوي على 6 حسابات وهمية و7 طلبات بحالات مختلفة، ومحادثات، وروابط مراجع وتسليم شكلية. **روابط Drive وهمية وليست ملفات قابلة للفتح.**

| مدرس فيزياء | `khaled@desk.demo` | طلب مكتمل وآخر مقبول. |

## التشغيل

من `desk/backend` في PowerShell:

```powershell
$env:DESK_DATABASE_URL = 'sqlite:///./desk-demo.db'
py -3 -m uvicorn app.main:app --reload --port 8000
```

ثم من `desk/frontend` بعد تثبيت حزم npm:

```powershell
npm.cmd install
npm.cmd run dev
```

افتح `http://localhost:5173` وادخل بأي حساب من الجدول. يمكن تجربة API مباشرة على `http://localhost:8000/docs` إن لم تكن حزم الفرونت متاحة بعد.

### معاينة فورية بدون npm

لو npm غير متاح، توجد واجهة معاينة مستقلة في `desk/frontend/preview/` تشتغل على نفس API ونفس قاعدة الديمو. شغّل الباك بالأمر أعلاه، ثم من داخل `desk/frontend/preview`:

```powershell
py -3 -m http.server 5173 --bind 127.0.0.1
```

افتح `http://localhost:5173`. الواجهة تعرض أزرار دخول سريعة لكل حساب، وتتيح تجربة إنشاء الطلبات، المحادثة، إسناد المدرسين، إضافة روابط Drive والتسليم. هذه معاينة محلية لتجربة الوظائف، والواجهة الأساسية React موجودة في `desk/frontend/src/`.

## إعادة إنشاء بيانات التجربة

`py -3 seed_demo.py` ينشئ ملف `desk-demo.db` إذا لم يكن موجودًا، ويرفض الكتابة فوق قاعدة موجودة. لو أردت البدء من الصفر، انقل أو احذف ملف الـDemo يدويًا أولًا ثم شغّل السكربت مجددًا. لا تستخدم حسابات أو كلمة مرور الديمو في النشر الحقيقي.
