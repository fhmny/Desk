# Creative Desk — وثائق المشروع

الـDesk مشروع مستقل داخل هذا المجلد لخدمة مدرسي فهمني. المدرس يطلب تصميم صورة أو مونتاج فيديو، ويتواصل مع المصمم في محادثة الطلب، ثم يراجع التسليم. الأدمن يضيف المصممين، يربط كل مدرس بمصمم، ويحدد رصيد الصور والفيديوهات كلًّا على حدة.

## تقسيم المجلد

| المسار | الغرض |
|---|---|
| `desk/frontend/` | واجهة React مستقلة للمدرس والمصمم والأدمن. |
| `desk/backend/` | خدمة Python/FastAPI للطلبات والمحادثات والأرصدة والروابط. |
| `desk/docs/` | مصدر الحقيقة لقواعد المنتج، التصميم، خطة التنفيذ، وقرارات التكامل. |

## القرارات المؤكدة

- الـDesk مشروع مستقل في `desk/` حاليًا، وله تسجيل دخول مستقل. الربط مع المنصة خطوة لاحقة.
- خدمة الـDesk الجديدة ببايثون، دون تعديل Laravel أو React الموجودين خارج `desk/`.
- الأدمن يحدد مصممًا لكل مدرس، وعدد الصور وعدد الفيديوهات بشكل مستقل.
- لكل طلب وصف وروابط مراجع ومحادثة بين المدرس والمصمم، ويستطيع الأدمن الاطلاع والمشاركة.
- المصمم يضع روابط Google Drive للمسودات والتسليم النهائي. المدرس يضع أي رابط HTTPS مناسب كمرجع. لا رفع صور أو فيديو على سيرفر المنصة أو خدمة الـDesk.
- المصمم يضغط «تم التسليم» بعد إضافة رابط Drive النهائي؛ يُحسب الطلب مكتملًا وقتها. التعديلات على نفس الطلب لا تستهلك طلبًا إضافيًا.
- كورسات الإنجليزي وبراند الملابس مشروعان منفصلان، ولكل منهما موقع مستقل مستقبلًا، مع إمكانية إضافة امتداد داخل المنصة لاحقًا.

ملفات Markdown الخاصة بالـDesk محفوظة هنا. الملفات الأقدم في `docs/` خارج هذا المجلد سجل بحثي سابق؛ عند التعارض، اعتمد وثائق `desk/docs/`.
