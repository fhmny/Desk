# خطة استكمال Creative Desk للإطلاق

**الهدف:** نقل النسخة المحلية داخل `desk/` إلى خدمة يمكن استخدامها تجاريًا دون لمس مشاريع المنصة الأخرى.

**الوضع الحالي:** راجع [حالة التنفيذ](../../IMPLEMENTATION_STATUS.ar.md) و[التصميم الحالي](../specs/2026-11-25-standalone-desk-design.md).

## 1. بناء الواجهة وفحصها

- من `desk/frontend`: تثبيت الحزم، ثم `npm run build`.
- مراجعة صفحة الدخول، المدرس، المصمم، والأدمن على عرض 375 و768 و1440 بكسل، ولوحة المفاتيح.
- إصلاح أي أخطاء TypeScript أو مشكلة عرض تظهر من البناء أو الفحص المرئي.

## 2. قاعدة بيانات الإنتاج والرصيد

- استبدال SQLite التطويرية بقاعدة إنتاج وإضافة migrations ونسخ احتياطية.
- جعل قبول الطلب وحجز الخانة في معاملة واحدة مع قفل مناسب أو تحديث شرطي.
- اختبار قبول طلبين متزامنين عند بقاء خانة واحدة؛ المطلوب قبول واحد فقط.
- اختبار الإلغاء والتسليم المكرر دون تغيير الرصيد مرتين.

## 3. إدارة الحسابات

- حد محاولات الدخول، تغيير/استرجاع كلمة المرور، وانتهاء الجلسات.
- مراجعة سياسات إيقاف المصمم الذي لديه طلبات نشطة، وإسناد تلك الطلبات لمصمم آخر بسجل واضح.
- تطبيق HTTPS وتهيئة CORS على عنوان الواجهة الحقيقي فقط.

## 4. سياسة الخدمة

- تحديد أقصى مدة للفيديو، عدد المقاسات، جولات التعديل، مواعيد التسليم، وسياسة النزاع.
- تحديد الأسعار والدفع قبل البيع. هذه قواعد تجارية وليست جزءًا من كود النسخة الأولى.

## 5. التكامل اللاحق مع فهمني

- بعد قرار منفصل بالدمج، صمم عقد هوية بين الـDesk والمنصة وراجع نشر الواجهة تحت مسار المنصة.
- أبقِ التغييرات الخاصة بالتكامل في مرحلة مستقلة؛ النسخة الحالية لا تعتمد على `client/` أو `server/`.
